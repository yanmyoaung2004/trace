Target: Take Trace from "usable for me" to "usable for my team."

## Gap 1: No Graceful Shutdown

**Problem:** Killing `trace serve` mid-flush orphans Parquet files. GC cleans up, but there's a window where the manifest is inconsistent.

### Tasks

| # | Task | File(s) | Effort |
|---|------|---------|--------|
| 1.1 | Add `sync.Mutex` to flusher for shutdown signaling | `internal/storage/flusher/flusher.go` | 30min |
| 1.2 | Add `Stop()` method that waits for in-flight flush to complete before returning | `internal/storage/flusher/flusher.go` | 1h |
| 1.3 | Wire `StopTSE()` to call `Flusher.Stop()` with a timeout | `cmd/trace/tse_init.go` | 30min |
| 1.4 | Add `os.Signal` handler for SIGTERM/SIGINT that triggers graceful shutdown | `cmd/trace/serve.go` | 30min |
| 1.5 | Test: verify kill → no orphan files, manifest consistent | `internal/storage/harness/crash_test.go` | 1h |

**Total: ~3.5h**

### Design

```go
type Flusher struct {
    // ...existing fields...
    stopCh chan struct{}
    doneCh chan struct{}
}

func (f *Flusher) Stop(ctx context.Context) error {
    close(f.stopCh)
    select {
    case <-f.doneCh:
        return nil
    case <-ctx.Done():
        return ctx.Err()
    }
}
```

**Problem:** If the disk dies, you lose the last ~1h of events (hot window). Cold Parquet files would survive if on S3.

| 2.5 | Test: write to S3, read back, verify SHA-256 | `internal/storage/parquet/writer_test.go` | 2h |

**Total: ~10h**

### Design

```go
type ParquetWriter struct {
    // ...existing fields...
    s3Client *s3.Client  // nil when using local filesystem
}
// Path format: s3://bucket/tenant/date/hour/file.parquet
```

The cold reader already reads files by path. If path starts with `s3://`, download from S3 first, then read as local file. S3 acts as a cache layer — files are cached locally on first read.

## Gap 4: No Rate Limiting at Ingest

**Problem:** Pointing 100 agents at `trace serve` overwhelms SQLite. The queue package exists but is not wired.

### Tasks

| # | Task | File(s) | Effort |
|---|------|---------|--------|
| 4.1 | Wire IngestQueue → BatchWriter → SQLiteHotStore as the default write path | `cmd/trace/tse_init.go` | 2h |
| 4.2 | Add spill-to-dir config for queue overflow | `internal/config/config.go` | 1h |
| 4.3 | Wire drop counter to metrics.Global.EventsDropped | `internal/storage/queue/queue.go` | 1h |
| 4.4 | Add `--tse-queue-capacity` flag | `cmd/trace/serve.go` | 30min |
| 4.5 | Test: sustained load with queue → no drops below capacity | `internal/storage/harness/load_test.go` | 1h |

**Total: ~5.5h**

### Design

```
Event → IngestQueue (channel, capacity=65536)
      → spill to disk (if channel full, write to temp files)
      → drop (if spill full, increment counter, return error)
      → BatchWriter (accumulate 1000 events or 250ms)
      → SQLiteHotStore.WriteBatch()
```

The current path is `WriteBatch → SQLiteHotStore.WriteBatch()`. New path replaces the direct call with the queue chain.

```go

    srv.ListenAndServeTLS(opts.CertFile, opts.KeyFile)

}
```
